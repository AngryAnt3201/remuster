The engine is deterministic and locked. The server re-fights every ladder match with it, so nobody can claim a win they didn't earn, in any game.

Everything else is yours: every sprite, screen, word, sound and tune. A remix that only recolours the base game doesn't pass the checks.

Every level is a real place

Streets, cover, bridges, ambushes. The battlefield is the top of a small globe: spin it, tip it, zoom it.
